## Q: What is `Emmet`?
Ans: `Emmet` in Visual Studio Code is a plugin that provides shorthand syntax for writing HTML and CSS, allowing developers to quickly generate code snippets. It speeds up the coding process by expanding abbreviations into complete code structures, improving efficiency and productivity in web development.

## Q: Difference between a `Library and Framework`?
Ans: `React (Library):`

`Definition:` React is a JavaScript library to build user interfaces, allowing developers to choose and manage their own structure and additional tools.

`Example:` React can be a cookbook. It offers specific recipes (tools) you can use to create various dishes (UI components) in your kitchen (application), allowing you the flexibility to decide how and when to use them.

`Nextjs (Framework):`

`Definition:` Next.js is a framework built on top of React that provides a structured way to develop web applications. It includes additional features like server-side rendering, static site generation, and routing out of the box.

`Example:` Next.js is more like a meal kit delivery service. It provides you with pre-measured ingredients and a step-by-step recipe (built-in features and conventions) to create a complete meal (application), streamlining the cooking process and ensuring consistency in the final dish.

## Q: What is `CDN`? Why do we use it?
Ans: A `Content Delivery Network (CDN)` is a network of servers spread across different locations to deliver web content quickly to users. We use CDNs to speed up the loading of websites and apps by storing copies of content closer to where users are accessing it.

## Q: What is `crossorigin in script tag`?
Ans: The `crossorigin` attribute sets the mode of the request to an HTTP CORS Request. The purpose of crossorigin attribute is used to share the resources from one domain to another domain. Basically, it is used to handle the CORS request. It is used to handle the CORS request that checks whether it is safe to allow for sharing the resources from other domains.
### _Syntax_
```
<script crossorigin="anonymous|use-credentials" src="source-path">
```
